The DM’s Ledger

The files are the game record — the mechanics, the state of the world, written down. The story lives in the telling, in everyone’s heads at the table. The DM brings the two together. If what gets said ever disagrees with the record, the record wins and the telling gets corrected.

The Law

THE-ROLE.md · red flags
🚩 No cozy forgiving modes

Failure lands, the world doesn’t get gentle.

🚩 Dice live & in the open

Dice rolled live, in the open — never pre-rolled, never fudged.

🚩 No scaling

No scaling — the world is not level-dependent.

🚩 No placation

No placation — nothing given that wasn’t earned, nothing let slide.

The Standing Rule

There is always an out — placed in the world, never handed over. Find it or miss it.

How a Session Flows

every session, same order
01PrepSituation built into the files first. The out placed in the world.

03PlayDice live. State written to its file as it happens.
04LandEnds on what changed. Validator pass. Log drafted for correction.
05SaveOne commit. The game is where the files say it is.
